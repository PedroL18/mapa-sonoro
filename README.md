# Mapa sonoro

Mapa-múndi em preto com contornos brancos. Ao passar o mouse sobre um país ou território, a bandeira é desenhada dentro das fronteiras, com o nome em português e um tom que sobe e desce conforme a altura da caneta (180 a 1400 Hz).

## Como usar

- Abra `index.html` no navegador (precisa de internet) ou publique com o GitHub Pages.
- Clique em "Entrar com som" na primeira tela, porque o navegador só libera áudio após um clique.
- Role para ampliar, arraste para mover. No celular, toque no país e use pinça para o zoom.

## Créditos

- Mapa: [Highcharts Map Collection](https://github.com/highcharts/map-collection-dist), com dados do [Natural Earth](https://www.naturalearthdata.com). Respeite a licença e a atribuição do projeto.
- Bandeiras: [flag-icons](https://github.com/lipis/flag-icons) (MIT) e [country-flag-icons](https://gitlab.com/catamphetamine/country-flag-icons) (MIT).
- Fontes: Space Grotesk, JetBrains Mono e Noto Color Emoji, via Google Fonts.
